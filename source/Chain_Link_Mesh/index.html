How chain link box size is measured (clear opening)

Mesh / box size is the clear inside opening between parallel wires of the diamond, fabric stretched - not center-to-center. GARG quotes 50 / 55 / 75 / 100 mm. Wire is 2.5 / 3 / 4 mm. Heights 3-10 ft. Rolls 50 ft. This matches India trade language and IS 2721-style clear-distance practice.

Five steps to measure box size on site

  1. Stretch a panel so diamonds are regular (not collapsed).
  2. Pick one diamond cell.
  3. Measure the shortest clear gap between one pair of parallel wires (inside edge to inside edge).
  4. Optionally measure the perpendicular pair and average.
  5. That millimetre number is the commercial box / mesh size (50, 55, 75 or 100 mm in our range).

How is chain link mesh / box size measured?

Mesh (box) size is the clear inside opening between parallel wires of the diamond, with the fabric in normal stretched condition - not center-to-center. GARG stocks 50 mm, 55 mm, 75 mm and 100 mm clear openings (about 2 inch, 2.2 inch, 3 inch and 4 inch).

Is mesh size center-to-center or clear opening?

Clear opening. Chain link box size is inside wire-to-wire on the diamond, not center-to-center pitch. Center-to-center on a true 50 mm opening with 3 mm wire can read about 53 mm, but the commercial size is still 50 mm.

GI vs MS chain link - which should I buy?

Choose GI (galvanized / galvanised) for outdoor and long-life boundary, industrial and farm fencing - zinc slows rust. Choose MS (mild steel) for budget or temporary work when you will paint or coat after install. For wet or long outdoor exposure we usually recommend GI.

Difference between 50 mm and 75 mm chain link?

50 mm clear opening is tighter - better deterrence for schools, compounds and industrial perimeters. 75 mm (about 3 inch) is a larger economy opening with less steel per square metre - common on farms and cost-sensitive runs. Wire diameter is still specified separately (2.5 / 3 / 4 mm).

3 mm vs 4 mm wire for boundary / industrial?

3 mm is the default commercial wire for compound, school and most boundary jobs. 4 mm is heavy-duty for industrial warehouses, farm pressure and security perimeters. Pair either with 50 or 55 mm box for tighter security; ask us if you are unsure.
