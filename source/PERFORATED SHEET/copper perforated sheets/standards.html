Standards thinking

ASTM B152 Copper Sheet - What Perforation Adds

Buy the sheet to a metal standard. Buy the holes to a drawing or pattern callout. Mixing those two into one vague sentence is how certificates get messy and arguments start on the receiving dock. At GARG INDUSTRIAL MESH, “ASTM B152” on a perforated quote means the base metal blank — not DIN hole-pattern compliance.

Don't order without…

Separating metal cert requirements from perforation acceptance. MTC for chemistry and temper ≠ first-article hole/pitch check. Different inspections. Different owners. Same PO line is not enough. Name the UNS grade — if the purchase order does not, ASTM B152 allows the supplier to furnish any copper listed in the specification.

ASTM B152 / B152M — the blank sheet standard

ASTM B152 / B152M is the product specification for copper sheet, strip, plate, and rolled bar made from listed UNS coppers (including C10100, C10200, C11000, C12200, and others such as C10300, C10800, C12000, silver-bearing tough-pitch grades, etc.).

It sets requirements for chemical composition, temper, mechanical properties, and (where specified) electrical resistivity, plus general requirements via ASTM B248/B248M. It applies to the unperforated mill product. Punching/perforating is secondary manufacturing; mill certificates typically cover the blank, not the finished perforated panel geometry.

B152M is the metric companion. Write the units you want on thickness and sheet size so nobody converts twice. Put the year of issue on the PO when it matters (e.g. B152/B152M-19 vs -24) so the mill cert matches the edition you ordered.

Spec tip

Stack the callouts on two lines: Material: ASTM B152 C11000, temper O60 then Perforation: Round 60° (Rv), Ø4.0 / pitch 6.0, blank edge 25 mm. Metal first. Holes second. Clear ownership.

What B152 covers — and what it does not

Covered by ASTM B152 (base sheet) Not covered — specify separately
UNS grade / chemical composition Hole diameter, pitch, open area %
Temper and mechanical property windows for sheet Blank edge / margin width
Electrical resistivity when specified as an ordering option Pattern orientation (60° / 90° / DIN Rv–Rg codes)
Hydrogen-embrittlement testing when specified as an ordering option Burr side, flatness after perforation, finished panel cut size beyond the blank
Mill testing / certification language for the copper product Packing, finish, visual acceptance after punch

Verified exclusions (do not misuse B152)

  • Not intended for material rolled to ounce-weight thicknesses → that is ASTM B370 (building construction sheet/strip).
  • Flat products with finished (rolled or drawn) edges (flat wire/strip) → ASTM B272.

Perforation is a process on top of the sheet

Think in layers:

  1. Buy / certify the blank to ASTM B152 (UNS grade + temper + thickness).
  2. Punch / perforate to a pattern callout or drawing (hole, pitch, orientation, OA% target, blank edge).
  3. Cut / finish / pack to finished size and site requirements.

There is no single ASTM number that means “this perforated copper panel is approved in full.” You approve metal to B152 (or agreed equivalent). You approve holes to print or agreed pattern tolerances. Mill B152 cert ≠ perforated dimensional inspection report. See copper sheet temper after punching for what punching does to the blank temper.

MTC — what to ask for

Say what you need in plain words on the PO. Certificates follow the blank.

Ask for… Why Notes
Chemistry (and UNS grade) Proves C11000 vs C12200 vs C10200/C10100 — not “copper” Required when grade is critical to joining or conductivity
Temper / mechanical properties Ties blank to O60 / H00–H04 windows Property limits live in B152 tables for the temper — ASTM B601 only names the code
Resistivity / conductivity if ordered B152 ordering option where specified Annealed reference ≠ measured after heavy perforation
Hydrogen-embrittlement testing if ordered B152 ordering option; ASTM B577 family for detection methods Relevant when C11000 will see reducing heat
Heat / lot / coil identity + B152 year Traceability; edition match Say if you need one cert per lot or per shipment

An MTC does not prove hole diameter, open area, or blank-edge width. Write metal inspection and perforation inspection as separate lines.

Spec tip

Example PO line: MTC required: chemistry + temper per ASTM B152/B152M-24 C11000 O60. First article: hole Ø, pitch, blank edge, OA% check on one sheet before full run.

What drawings and RFQs must include

  • Material: ASTM B152 / B152M (edition if required) + UNS grade — never leave UNS blank if grade matters
  • Temper code (O60, H01, H02, H04… — soft / half-hard / hard alone is informal)
  • Thickness × finished width × length (mm preferred)
  • Hole shape + size + pitch + orientation (or DIN-style Rv / Rg string)
  • Open area % target for the perforated field — or enough geometry to calculate it (OA formulas ignore blank margins)
  • Blank edge all around, or per side if unequal (sketch if unequal)
  • Quantity; burr side if flow or finish cares; flatness note if critical (agree separately on soft copper — do not assume steel DIN flatness tables)
  • Finish / packing; MTC and FA inspection if required
  • One sentence of end use

DIN 24041 pattern naming — holes, not copper chemistry

European trade still talks in DIN 24041-family abbreviations for perforated plates. Useful shorthand for geometry. Independent of material type for the dimensional naming system. It is not a substitute for ASTM B152, and it does not automatically import steel/aluminium machining or flatness guarantees for copper.

Code Meaning GARG catalogue thinking
Rv Round holes, 60° staggered rows Round 60°
Rd Round holes, diagonally staggered Say “diagonal stagger” on the RFQ if that is what you mean
Rg Round holes, straight rows Round 90°
Qg / Qv / Qd Square holes (straight / staggered / diagonal per code) Square 90° common; confirm stagger if not straight
Hex (trade) Hexagonal openings — codes vary by source edition (HV / SKv) Hex 60° — send print if non-standard

Specification form in industry: Rv w – t. Example: Rv 5–8 = round staggered, hole width (diameter) w = 5 mm, pitch t = 8 mm centre-to-centre. Related symbols: w hole width, t pitch, c bridge (≈ t − w for equal round holes in the simple case), e₁,e₂ / f₁,f₂ blank margins, A₀ relative open surface of the perforated field.

Copper caveat: machining/processing tolerances stated in DIN 24041 documentation are for steel up to 750 MPa tensile strength and aluminium — not formally calibrated as copper tolerance tables. Soft copper with wide or unequal blank margins, high open area, or unperforated bands tends toward larger flatness / sabre deviations; acceptable flatness should be agreed separately. Citing “DIN 24041” on a copper PO correctly means pattern geometry naming.

Do not confuse DIN 24041 pattern codes with ISO 7805, sieve standards, or quality marks sometimes listed beside “ISO 24041” on fabricator sites without checking the document. Exact table values require the purchased DIN edition — use drawings for contractual dimensions. Custom hole sizes, pitches, open areas, and orientations available on order from GARG.

How GARG documents a job

Base metal grade + temper + thickness. Pattern (shape, hole, pitch, orientation). Blank edge. Finished size. Qty. Optional: OA% target, burr side, flatness note, finish, packing, MTC. That is enough to quote and produce without inventing missing fields.

Material: ASTM B152 C11000, temper H02, MTC chemistry + temper Perforation: Round 60° (Rv) Ø3.0 / pitch 5.0, OA ~32% field, blank edge 20 mm all sides Size: 1.0 × 1000 × 2000 mm, qty 50 Inspection: FA hole/pitch on sheet 1; packing paper interleaved
Don't order without…

Writing grade + ASTM B152 on the metal line, and hole/pitch/orientation/blank edge on the perforation line. “Perforated copper per ASTM” alone does not tell us the pattern. “Rv 5–8 copper” alone does not tell us the grade.
